# Lotka-Volterra PINN
A specialized Physics-Informed Neural Network (PINN) in TensorFlow to solve the Lotka-Volterra differential equations (also known as the predator-prey model).

My BSc honours thesis, which was submitted in the winter semester of 2023, was based on this project. You can find the full pdf document [here](https://drive.google.com/file/d/1UC-dalcICiBvEYLcu57No7iN1CjLazBO/view?usp=sharing).
